## 📚 ТЕОРЕТИЧЕСКАЯ ЧАСТЬ (15 минут)

1. Зачем нужен README.md?

README.md — это главный файл в репозитории. Он объясняет:

Что это за проект;

Какие технологии использованы;

Что умеет приложение;

Как его запустить.

Зачем README.md на ДЭ:

Модуль 4, задание 4.4: обязательный файл в репозитории;

Эксперт проверяет, что в README есть 4 обязательных раздела;

Без README.md снимают баллы.

2. Что должно быть в README.md (по требованию ДЭ)?

Из КИМ ДЭ (Модуль 4, задание 4.4):

«В файле укажите:

Название приложения, включающее название компании-заказчика.

Используемые технологии: язык программирования, платформу или фреймворк и СУБД.

Краткое описание назначения и основных функций системы, включая работу с каталогом, оформление заказов и управление заказами.

Порядок подготовки базы данных и запуска приложения».

Обязательные разделы:

| № | Раздел | Что писать |
|---|---|---|
| 1 | Название приложения | «Мир фитнеса — Система оформления заказов» |

Создание README.md:

# Мир фитнеса — Система оформления заказов

## 1. Название приложения

**Мир фитнеса** — приложение для продажи инвентаря и аксессуаров для тренировок.

## 2. Используемые технологии

- **Язык:** Python 3.13+

- **GUI:** PySide6 6.8+

- **СУБД:** PostgreSQL 18.6

- **Драйвер БД:** psycopg2-binary 2.9.10+

## 3. Назначение и основные функции

Приложение автоматизирует продажи. Функции:

- Каталог моделей (изображение, категория, производство, описание, состав, цена «от», варианты исполнения и остатки);

- Авторизация по логину;

- Фильтрация, сортировка, поиск;

- Оформление заказа;

- Управление заказами (Менеджер, Администратор).

## 4. Порядок подготовки БД и запуска

1. Установите PostgreSQL 18.6 и запустите службу PostgreSQL.

2. Создайте БД `fitness_db` и загрузите данные: `psql -U postgres -f db/database.sql`.

3. Установите зависимости: `pip install -r requirements.txt`.

4. Запустите: `python main.py`.

5. Типичные ошибки и решения

| Нет 4 разделов | Забыли | Добавьте все 4 |

| Нет технологий | Забыли | Добавьте Python, PySide6, PostgreSQL |
| Нет порядка запуска | Забыли | Добавьте шаги |
