# Мир фитнеса — Система оформления заказов

## 1. Название приложения

**«Мир фитнеса»** — учебное приложение для компании «Мир фитнеса», которая продаёт
инвентарь и аксессуары для тренировок. Тема 18 учебной практики УП.11.

Автор: Анфалов Даниил Дмитриевич, группа 3ИП-1-24.

## 2. Используемые технологии

- **Язык:** Python 3.13+
- **GUI:** PySide6 6.8+
- **СУБД:** PostgreSQL 18.6
- **Драйвер БД:** psycopg2-binary 2.9.10+
- **Импорт данных:** pandas, openpyxl
- **Редактор:** Visual Studio Code
- **VCS:** Git + GitHub

## 3. Назначение и основные функции

Приложение автоматизирует продажу инвентаря и аксессуаров для тренировок.

- Каталог моделей: изображение, категория и подкатегория, производство,
  наименование, описание, состав, базовая цена «от», варианты исполнения
  и остатки по каждому варианту.
- Заглушка `picture.png` для модели без изображения.
- Подсветка модели с суммарным остатком не более трёх штук цветом `#ff8080`
  (включая нулевой остаток) и надпись «Недоступно для заказа».
- Авторизация по логину без пароля, режим гостя.
- Роли: гость — просмотр каталога; авторизованный пользователь — каталог,
  поиск, фильтр, сортировка, корзина и оформление собственного заказа;
  менеджер — просмотр и удаление заказов; администратор — дополнительно
  изменение даты заказа и удаление отдельных строк.
- Поиск по наименованию, фильтр по категории (с пунктом «Все категории»)
  и сортировка по базовой цене по возрастанию и убыванию.
- Корзина: изменение количества, удаление, повторная проверка остатков
  и актуальных цен при подтверждении, атомарное сохранение заказа.
- При удалении заказа или строки остаток возвращается в каталог.
- Оформление по руководству по стилю: шрифт Calibri, фон `#FFFFFF`,
  дополнительный фон `#D2F6E7`, акцент `#70B2AF`, суммы с двумя знаками
  после запятой и знаком рубля, даты в формате ДД.ММ.ГГГГ.

## 4. Порядок подготовки базы данных и запуска

1. Установите PostgreSQL 18.6 и запустите службу.
2. Создайте базу и загрузите данные одним скриптом (база `fitness_db`
   пересоздаётся):

   ```bash
   psql -U postgres -f db/database.sql
   ```

3. Перейдите в папку проекта и установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

4. Запустите приложение:

   ```bash
   python main.py
   ```

5. Войдите под одним из логинов: `admin` (администратор), `manager1`
   (менеджер), `client01` (авторизованный пользователь) или нажмите
   «Продолжить как гость».

Параметры подключения заданы в `database.py` и могут быть переопределены
переменными окружения `FITNESS_DB_HOST`, `FITNESS_DB_PORT`, `FITNESS_DB_NAME`,
`FITNESS_DB_USER`, `FITNESS_DB_PASSWORD`.
